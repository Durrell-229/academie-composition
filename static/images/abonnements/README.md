# 📁 Images Publicitaires pour la Page d'Abonnement

Ce dossier contient les images utilisées pour la page d'abonnement et les promotions.

## Images Requises

### 1. `hero-bg.jpg`
- **Usage**: Image de fond de la section Hero
- **Dimensions recommandées**: 1920x1080px
- **Style**: Élèves africains utilisant des tablettes/ordinateurs, ambiance moderne et éducative
- **Couleurs dominantes**: Bleu, violet (pour matcher le design)

### 2. `promo-student.png`
- **Usage**: Image de l'étudiant dans la section promotion
- **Dimensions recommandées**: 600x800px
- **Style**: Élève souriant avec un livre ou tablette, fond transparent (PNG)

### 3. `placeholder-promo.jpg`
- **Usage**: Image de fallback si les autres ne chargent pas
- **Dimensions**: 800x600px

## Sources d'images suggérées

1. **Unsplash** (gratuit): https://unsplash.com/s/photos/african-students-technology
2. **Freepik** (gratuit/payant): https://www.freepik.com/search?query=african%20students%20learning
3. **Pexels** (gratuit): https://www.pexels.com/search/african%20students/

## Conseils

- Utilisez des images avec des élèves africains pour matcher le contexte béninois
- Privilégiez des images montrant la technologie et l'éducation
- Assurez-vous que les images sont optimisées (compressées) pour le web
- Format: JPG pour les photos, PNG pour les images avec transparence

## Génération d'images avec IA

Vous pouvez aussi générer des images avec des outils comme:
- Midjourney
- DALL-E 3
- Stable Diffusion

**Prompt suggestion**:
```
"African students in a modern classroom using tablets and laptops, 
bright and colorful atmosphere, blue and purple gradient background, 
professional photography style, high quality, 4K"
```
